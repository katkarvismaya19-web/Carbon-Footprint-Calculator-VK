\# Week 4 – Application Development and Build Automation



\## Objective



The objective of Week 4 was to develop and prepare the Java application for automated building and testing.



\## Work Completed



\* Worked with the Java application source code.

\* Organized the project source and test structure.

\* Configured Apache Ant using `build.xml`.

\* Configured Java compilation for JDK 21.

\* Configured JUnit test compilation and execution.

\* Created the WAR packaging process.

\* Verified successful local application builds.

\* Prepared the application for deployment on Apache Tomcat.



\## Build Process



The Ant build process includes:



1\. Clean previous build files.

2\. Initialize build directories.

3\. Compile Java source code.

4\. Compile test classes.

5\. Execute unit tests.

6\. Generate code coverage.

7\. Copy web application files.

8\. Create the WAR package.



\## Outcome



The application could be compiled, tested and packaged into a deployable WAR file using Apache Ant.
