\# Week 3 – Requirements, Architecture and Technology Setup



\## Objective



The objective of Week 3 was to define the functional and technical requirements of the Carbon Footprint Calculator and establish the application architecture and development environment.



\## Work Completed



\* Reviewed the existing Carbon Footprint Calculator application.

\* Identified functional and non-functional requirements.

\* Defined the application workflow.

\* Defined the application architecture.

\* Planned the source code, testing and deployment structure.

\* Set up the Java development environment.

\* Configured Apache Ant for application builds.

\* Prepared the project for Git and GitHub integration.

\* Identified Jenkins, Tomcat, Selenium, Docker and Ansible for the DevOps workflow.



\## Technology Stack



\* Java

\* Apache Ant

\* JUnit

\* Git

\* GitHub

\* Jenkins

\* Apache Tomcat

\* Selenium

\* Maven

\* Docker

\* Docker Compose

\* Ansible

\* WSL



\## Outcome



The application requirements, architecture, technology stack and development environment were established.
